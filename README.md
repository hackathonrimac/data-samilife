## 📖 Cómo funciona este repositorio

Este repositorio funciona como tu **cuaderno de bitácora progresivo** durante el hackathon:

1. **Un solo repositorio, tres entregas:** No crees repositorios nuevos. Este mismo repo se actualiza 3 veces.
2. **Entregas progresivas:** Cada entregable construye sobre el anterior. Completa cada archivo en su momento y guarda los cambios.
3. **Proceso simple por entregable:**
   - 📝 Abre el archivo correspondiente (ej: `01_equipo/equipo.md`)
   - ✍️ Completa las secciones respondiendo las preguntas
   - 💾 Guarda los cambios (commit)
   - 🚀 Súbelos a GitHub (push)
4. **Todo queda documentado:** Tu historial de commits muestra tu progreso durante las 48 horas.

> **💡 Tip:** Haz commit frecuentemente. No esperes a tener todo perfecto para guardar.

## 🚀 Cómo trabajar con este repo

**Opción A - Desde GitHub (más simple):**
1. Haz clic en el archivo que necesitas editar
2. Presiona el ícono del lápiz (✏️) para editar
3. Completa las secciones
4. Haz scroll hacia abajo y presiona "Commit changes"

**Opción B - Localmente (recomendado para equipos con código):**
```bash
git clone [URL-de-este-repo]
cd template
# Edita los archivos con tu editor favorito
git add .
git commit -m "Entregable 1 completo"
git push
```

**Tips adicionales:**
- Sube imágenes o diagramas en la carpeta `assets/`
- Usa commits con mensajes claros: "Completar entregable 1", "Actualizar arquitectura", etc.
- Si trabajas en equipo, coordina quién edita qué para evitar conflictos

## 💡 Consejos para el hackathon

- **Documenta desde el inicio:** No dejes toda la documentación para el final.
- **Commits frecuentes:** Guarda tu progreso regularmente en GitHub.
- **Enfócate en el impacto:** Piensa en cómo tu solución contribuye al bienestar de los peruanos.
- **Sé específico:** En lugar de "creamos una app", escribe "desarrollamos un asistente médico que reduce el tiempo de búsqueda de doctores en 70%".
- **Usa diagramas:** Una arquitectura visual vale más que mil palabras.
